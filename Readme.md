# Botium Toys Cybersecurity Risk Assessment

## Project Overview
This beginner-level portfolio project analyzes the security risks, existing controls, and compliance gaps described in the fictional Botium Toys case study.

## Objectives
- Review the organization's assets and existing security controls.
- Identify weaknesses in access management, encryption, backups, and intrusion detection.
- Review relevant PCI DSS, GDPR, and SOC control considerations.
- Recommend improvements to reduce risk and protect customer information.

## Recommendations
- Apply least privilege and separation of duties.
- Strengthen password requirements and password management.
- Encrypt sensitive data.
- Establish regular backups and a disaster recovery plan.
- Evaluate intrusion detection and improve asset inventory and monitoring.
- Review applicable compliance requirements.

## Skills Demonstrated
Security risk assessment, security controls review, asset management, compliance checklist analysis, risk prioritization, and documentation.
